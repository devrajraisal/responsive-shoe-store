# Responsive Shoe Store

Two small, responsive websites built with plain HTML, CSS, and JavaScript. There is no build step and no dependencies, so each site runs by opening its HTML file.

These are practice projects. The shoe store uses Nike branding and sample prices only to practise layout and interaction. It is not affiliated with Nike and it cannot be used to buy anything.

## What is inside

| Folder | What it is |
| --- | --- |
| Root (`index.htm`) | A shoe store landing page with a product menu, colour options, and size options |
| `Premium cars website/` | A car rental landing page with a responsive navigation menu |

## Shoe store

- Pick a shoe from the menu and the page updates the product image, title, and price
- Choose a colour and the image changes to match
- Choose a size from the size options
- Layout adapts to phones, tablets, and desktops

## Car rental site

- Landing page sections for the hero, vehicle fleet, and call to action
- Mobile menu that opens and closes with a button and closes again when a link is tapped

## Run it

```bash
git clone https://github.com/devrajraisal/responsive-shoe-store.git
cd responsive-shoe-store
```

Open `index.htm` for the shoe store, or `Premium cars website/index.html` for the car rental site.

## What I practised

- Responsive layouts with CSS
- Updating the page from data with plain JavaScript
- Building a mobile navigation menu
